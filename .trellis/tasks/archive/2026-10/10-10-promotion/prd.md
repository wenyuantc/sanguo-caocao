# 兵种体系与转职（全面按原版）

## Goal

把兵种和能力系统换成原版《三国志曹操传》的体系：
- 原版兵种系列与三阶名称、每阶移动力与攻击范围；
- 五项能力（攻击、精神、防御、爆发、士气），原版 HP/MP 公式；
- 我军武将改用原版兵种；
- 敌方特殊兵种；
- 15 级、30 级使用印绶转职。

依据：`../10-10-core-systems/research/class-tiers.md`；父任务决定 D1。

## Background（代码现状）

- `src/data.js` 的 `CLASSES` 共 12 个一阶兵种，能力为 `hp / mp / atk / def / int / agi`，属性 = 基础 + 成长 × (lvl − 1) + bonus。
- `logic.js` 的 `physDamage / hitRate / critRate / spellDamage / spellHit / healAmount` 使用 `atk / def / int / agi`。
- 外形：`heroSprites.js` 的 `CLASS_LOOK` 按兵种 id 配置；`characters.js` 按名字登记个性外形。
- 各关单位定义的 `cls` 是当前兵种 id。我军武将会被子任务 1 的 `generals.js` 统一覆盖，敌军和友军保留关卡数据中的兵种。

## Requirements

- C1 **兵种系列**：13 个可转职系列，含三阶名称、移动方式、相克类型、每阶移动力、每阶攻击范围、五项成长档（S/A/B/C = 每级 +4/+3/+2/+1）、基础 HP/MP 与每级成长，全部按 research。
  - 系列：君主、步兵、弓兵、骑兵、弓骑兵、炮车、武道家、贼兵、策士、风水士、道士、骑马策士、舞娘。
  - 文官系普通攻击范围查不到，设计为十字 → 周围 8 格，标注“自行设计”。
  - 炮车二阶射程有冲突，采用 4~5 格（多一个来源支持）。
- C2 **单阶特殊兵种**：本项目关卡用得到的，按 research 加入：西凉骑兵、黄巾贼、海盗、都督、咒术士、皇帝、百姓、辎重队。
  - 用武将登记表按名字指定，例如吕布、马超、华雄为西凉骑兵，周瑜、陆逊为都督，诸葛亮为咒术士，甘宁、周泰为海盗，献帝为皇帝。
  - 通用名的敌兵按关卡数据中的兵种映射到对应系列。
- C3 **能力与公式**：
  - 能力改为 `hp / mp / atk / int / def / burst / morale`（攻击、精神、防御、爆发、士气）。
  - HP/MP = 兵种基础 + 武将加成 + 每级成长 × (等级 + 2 × 已转职次数)。
  - 五项 = 兵种系列基础值 + 成长档 × 等级 + 武将加成；武将个人修正（如“爆发升 A”）调整成长档。
  - 物理命中、会心、伤害改用爆发、士气等；策略命中改用“精神 + 士气”。
  - 具体公式能查到的照搬，查不到的自行设计并标注；目标是普通难度下数值量级与现状相近。
- C4 **我军武将改为原版兵种**（武将总表中的 `cls` 字段）：曹仁骑兵、曹洪步兵、李典步兵、荀攸风水士、郭嘉道士、于禁弓兵、刘晔炮车、许褚贼兵、徐晃弓兵、夏侯渊和张郃弓骑兵、司马懿骑马策士、庞德步兵，其余按 research §6。新加入的满宠（风水士）、貂蝉（舞娘）、曹丕（弓骑兵）同样按 research。
- C5 **转职**：
  - 我军达到 15 级（一阶 → 二阶）、30 级（二阶 → 三阶）时，可以在道具菜单对其使用“印绶”。
  - 转职后兵力、策略值回满，播放转职特效，日志提示。
  - 未达等级时印绶不可用，并显示原因。
  - 转职后补学当前等级下该阶可学的策略（策略表由子任务 3 提供；本子任务先留接口）。
- C6 **印绶获取**：
  - 过关奖励按关卡进度发放；
  - 原版从第 16 关徐州入侵战起商店有售，商店由子任务 4 实现，本子任务先用过关奖励。
- C7 **敌军阶级**（用户决定，2026-10-10）：敌军和友军按等级自动定阶，门槛随难度：普通难度 ≥20 二阶、≥35 三阶；困难、地狱 ≥15 二阶、≥30 三阶。显示对应名称、外形、射程。第 6 个子任务重做地图时会逐关复核难度。
- C8 **外形**：
  - 新系列补外形：骑马策士、舞娘、炮车（已有）、武道家（已有）等；西凉骑兵、海盗、都督、咒术士、皇帝、百姓、辎重队也补上。
  - 二阶：金边、披风；三阶：华丽盔甲，骑马单位的马匹披甲。
  - 兵种标识字和信息面板显示阶级名称。
- C9 **兼容**：
  - 旧存档的 roster 没有 `tier`，视为一阶；
  - 战斗中存档的单位旧能力字段在读档时按新公式重新计算，不报错。
- C10 **难度复核**：能力和公式换成原版后，普通难度下代表关卡不应明显失衡。验收时用我军 AI 打颍川、官渡、赤壁，必要时调整 `DIFFICULTIES` 或公式系数。

## Acceptance Criteria

- [ ] 信息面板显示五项能力和原版兵种 / 阶级名称；我军武将兵种与 research §6 一致。
- [ ] 15 级、30 级用印绶转职后，名称、移动力、攻击范围、能力、外形变化正确；未达等级时不可用。
- [ ] 敌军按等级显示对应阶级；吕布显示为西凉骑兵，诸葛亮为咒术士，周瑜为都督等。
- [ ] HP 公式抽查：曹操 50 级、二次转职、武将加成 +2 时，HP = 100 + 2 + 5 × (50 + 4) = 372（与 research 原文例子一致）。
- [ ] 旧存档（本任务之前的格式）读档后能正常继续。
- [ ] 颍川、官渡、赤壁用我军 AI 完整对战，结果合理（不会一两回合内全灭或被全灭）。
- [ ] 校验 0 错误，构建通过，57 关回归无运行时错误。

## Out of Scope

- 仙人、驯熊师、驯虎师、木人、土偶等本项目关卡用不到的兵种；地形适性差异。
