# 金手指功能

## 目标

为玩家提供可选的金手指（作弊）功能，降低通关难度；使用过金手指的进度在存档中永久标识，便于区分正常进度。

## 需求

### 开关入口
- R1 标题画面「游戏设置」中新增「金手指」总开关（开 / 关），即时保存到本地设置（不进入存档）。
- R2 战斗中「设置」面板（audioOnly 战斗设置）同样可以切换金手指总开关，即时生效。
- R3 总开关打开后，分项效果可单独开关（默认全部开启）：
  - 我方无敌：我方（player）单位受到的伤害（物理、反击、策略、中毒）为 0。
  - 我方秒杀：我方单位攻击 / 伤害策略命中即击杀目标。
  - 无限行动：我方单位行动（攻击 / 策略 / 道具 / 待机）后不置灰，可再次移动与行动；回合需手动「结束回合」。

### 资源编辑（金手指面板）
- R4 总开关打开时，战斗中与营中可打开「金手指」面板：
  - 设置军资金：可直接输入 / 调整为任意非负整数（上限 9999999）。
  - 道具：可为任意道具（含全部果子）增加数量。
  - 装备：可从全部装备（含宝物）中选择并加入背包。
  - 鼠标移到（或点击）道具 / 装备上时，面板下方显示属性说明（装备含等级、属性、特效、可装备兵种）。
  - 出阵整备面板（战前 / 营中）在金手指开启时于军资金左侧提供「金手指」入口。
- R4b 金手指开启时，招募页的武将候选可无限刷新（不扣本关刷新次数）。
- R5 一键胜利：战斗中的金手指面板提供「直接胜利」按钮，立即按本关正常胜利流程结算（奖励、剧情、存档、进入下一关）。

### 存档标识
- R6 一旦在本周目中使用过金手指（总开关开启状态下进入/处于战斗或营中，或在战役中打开开关），本周目永久标记为金手指进度；之后关闭开关也不清除。
- R7 标记写入所有存档（手动存档、自动存档、导出文件），读档后继承。
- R8 存档列表（存档 / 读档界面）对带标记的存档在难度标签旁显示醒目的「金手指」标签。
- R9 开始新游戏时标记重置（若开关仍开着，进入战斗即重新标记）。
- R10 旧存档（无该字段）视为未使用金手指。

## 验收标准
- [ ] 标题设置与战斗设置都能切换金手指开关，刷新页面后开关状态保留。
- [ ] 开关关闭时，所有金手指效果不生效、金手指面板入口不可用。
- [ ] 无敌 / 秒杀 / 无限行动分项按预期生效，敌军回合不受影响（仅作用于 player 阵营）。
- [ ] 金手指面板可修改军资金、增加任意道具与果子、加入任意装备，修改后在整备 / 商店界面可见并随存档保存。
- [ ] 「直接胜利」走正常胜利结算，不出现卡死或重复结算。
- [ ] 开过金手指后保存的存档在存档列表显示「金手指」标签；关掉开关再存档仍显示；读档后再存档仍显示。
- [ ] 新游戏（开关关闭）的存档无标签；旧存档无标签且读写正常。
- [ ] `node scripts/validate-stages.mjs` 零错误，`npm run build` 通过。

## 不在范围内
- 结局记录 / 宝物图鉴不做金手指区分。
- 不对友军（ally）生效。
