# 补齐原版核心系统

## Goal

让本项目在玩法系统上接近原版《三国志曹操传》（光荣 1998）：战前可以整备出阵，策略种类丰富并有异常状态，武将可以转职，有装备与宝物可以收集和成长。
用户在对比原版后选定这四项全部补齐。

## Background（现状，已在代码中确认）

- 全部 57 关已实现，校验 0 错误，`npm run build` 通过，57 关自动对战回归无运行时错误。
- 每关我军阵容写死在 `src/stages/<组>.js` 的 `units` 中，没有战前整备界面。
- `src/data.js`：12 个兵种，无转职；`SPELLS` 只有火计、落石、援队、大援队；`ITEMS` 只有豆、麦、酒。
- 没有异常状态，没有装备。
- 战役状态存放在 registry（`difficulty`、`roster`、`items`、`red`、`flags`），存档见 `src/saves.js`。

- R2 新增的战役状态全部进入：新游戏重置、`snapshot()`、`writeAuto`、`applyLoad`、导出/导入；旧存档缺字段时给默认值，能正常读取并继续游玩。
- R3 遵守 `.trellis/spec/frontend/` 规范：规则保持在 `logic.js` 等纯函数中；数据可被 Node 导入；界面使用 `ui.js` 工厂函数；中文文案。

## 研究发现（research/，影响范围的决策）

- 原版 13 个可转职系列 + 14 个单阶特殊兵种；本项目缺少“骑马策士”“舞娘”两个我方系列。
- 本项目多名我军武将的兵种与原版不同（研究 class-tiers.md §6）：
  - 曹仁原版为骑兵（现为步兵），曹洪为步兵（现为骑兵），李典为步兵（现为弓兵）；
  - 荀攸为风水士，郭嘉为道士，于禁为弓兵，刘晔为炮车，许褚为贼兵，徐晃为弓兵；
  - 夏侯渊、张郃为弓骑兵，司马懿为骑马策士，庞德为步兵。
- 原版策略约 70 种，按系列和等级习得（spells.md）。“火计”不是原版名称，原版火系为灼热 / 烈火 / 火阵 / 火龙 / 爆焰；“落石”“援队”是原版名称。
- 原版能力为攻击、精神、防御、爆发、士气五项；本项目是武力、防御、智力、敏捷四项。
- 天气相关策略（晴明、昙天、豪雨）和四神的天气条件，依赖天气系统（按 D4 并入本任务）。

## Key Decisions

- D1（用户决定，2026-10-10）**全面按原版对齐**：
  - 我军武将改为原版兵种（由 `src/generals.js` 统一覆盖，不逐关修改关卡数据）；
  - 补齐原版兵种系列（含骑马策士、舞娘）及三阶名称、移动力、攻击范围；
  - 策略改用原版名称和整套体系（约 70 种，按系列与等级习得）；
  - 能力值改为原版五项：攻击、精神、防御、爆发、士气。
  - 依赖天气的策略和条件由天气子任务实现（见 D4）。
  - 代价：57 关中相关武将的打法和平衡会变化，需要重新调整难度（纳入验收）。
- D2（用户决定，2026-10-10）**装备与宝物全部 87 种**：
  - 50 种宝物按原版效果和取得条件实现；普通装备补齐 37 种；商店按原版的关卡上新顺序。
  - 价格和普通装备的数值查不到，自行设计并标注。
  - 四神宝玉效果由天气子任务完成后生效（见 D4）。
- D3（由 D1 推导）原版有、而本项目我军缺少的武将（满宠、貂蝉、曹丕）按原版加入时机加入武将总表，只进入出阵候选，不改关卡对白。
- D4（用户决定，2026-10-10）**原版其余系统全部并入本任务**：天气（含天气策略和四神）、大地图滚动、剧情场景演出、音效与配乐、城镇自由走动、二周目继承。各自作为子任务，按依赖顺序实施；动手前先查证原版资料。
- D5（用户决定）**大地图自行设计**：只参考原版尺寸（20×20 ~ 40×40，research/maps.md）和战场形态，不使用原版地图数据；57 关地图按原版尺寸重新设计，单位站位随之重排。地形种类和规则参考原版 30 种地形补齐。
- D6（用户决定）**做自由走动（超出原版）**：原版只有军营里点击部下交谈（research/scenes.md），本项目扩展为在军营 / 城镇场景中操控曹操行走、走近人物对话，再进入整备与出征。
- D7（用户决定）**配乐与音效程序合成**：用 Web Audio 实时合成中国风曲子和音效，不使用任何音频文件；按原版各场合的用曲分配（research/audio.md）。
