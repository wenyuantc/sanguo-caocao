# 游戏加速设置（1x~16x）

## Goal

新增“游戏速度”设置，可选 1x / 1.25x / 1.5x / 2x / 4x / 8x / 16x。首页“游戏设置”和战斗中“设置”都能调整，即时生效、写入本地设置并在下次进入时保留。

## Requirements

- `src/settings.js` 新增设置项 `speed`，默认 `1`，可选值 `1, 1.25, 1.5, 2, 4, 8, 16`；非法或缺失值回退默认（沿用 `loadSettings` 校验）。
- `speed` 不属于渲染类设置：修改后立即保存并生效，不触发页面重载。
- 设置面板新增一行“游戏速度”，7 个选项按钮，选中高亮：
  - 首页完整设置面板：加在画面设置与音量之间（面板高度相应增加，不与现有行重叠）。
  - 战斗中设置面板（当前为 `audioOnly` 的音量面板）：同样显示该行，标题与提示文案相应调整。
- 生效范围：战斗场景（BattleScene）内所有基于 Phaser `tweens` / `time` 的动画与等待——移动、攻击、法术特效、敌军回合、战斗内对白打字等，统一乘以速度倍率。
  - 实现方式：`this.tweens.timeScale = this.time.timeScale = SETTINGS.speed`，在战斗场景创建时及设置变更时应用。
- 不影响：剧情场景（StoryScene 保留现有“按住加速/跳过”逻辑）、营帐、标题、结局场景；音乐与音效播放速度不变。

## Acceptance Criteria

- [ ] 首页“游戏设置”可看到“游戏速度”7 档，点击后高亮切换，刷新页面后选择保留。
- [ ] 战斗中点“设置”可看到并切换速度，关闭面板后战斗动画即按新倍率播放，无需重载。
- [ ] 选 16x 时移动/攻击/法术/敌军回合明显加速，流程不卡死、不跳过结算；选 1x 与改动前表现一致。
- [ ] 剧情场景速度不受该设置影响。
- [ ] localStorage 中 `speed` 为非法值时回退为 1x。
- [ ] `npm run build` 通过。

## Notes

- 轻量任务，PRD-only。
- 风险点：基于 `time.now` 的防误触判断（如 `endGuard`）不受 timeScale 影响，保持现状即可；如有使用 `setTimeout` 的战斗逻辑需确认（目前战斗逻辑未发现）。
