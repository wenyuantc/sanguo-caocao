# 实施计划：适配移动端

## 步骤

1. `index.html`：viewport、触控 CSS、竖屏遮罩 → 验证：触屏模拟竖屏出现遮罩，横屏消失。
2. `config.js` 导出 `IS_TOUCH`；`main.js` 首触全屏 / 横屏锁定、阻止 gesturestart → 验证：构建通过、桌面无变化。
3. `mapCamera.js` 边缘滚动排除触屏、触屏点击容差 → 验证：大地图关卡触屏点击边缘后镜头静止；带少量位移的轻点仍算点击。
4. `BattleScene.js`：触屏补刷悬停、二次确认、取消按钮、提示文案 → 验证：触屏攻击两次点击才执行，取消按钮按状态显隐。
5. `hud.js` 天气说明触屏保持 → 验证：点天气后预测区保留说明。
6. `ui.js` 按钮 `onRelease` 选项 + `saveMenu.js` 导入 / 导出 → 验证：触屏抬起才触发，鼠标行为不变。
7. 标题 / 营中 / 剧情 / 整备 / 图鉴的说明文字按设备切换 → 验证：触屏模拟下文字为触屏版本。

## 验证命令

```bash
npm run build
```

- 浏览器预览：`preview_resize` 到 844×390 并模拟触屏（mobile 预设宽度 < 768 才模拟触屏，横屏需自定义尺寸 + 刷新；必要时用 `preview_eval` 派发 TouchEvent / 检查 `wasTouch` 分支）。
- 桌面回归：鼠标悬停、右键取消、ESC、边缘滚动、键盘滚动。

## 评审门

- 每一步改动只触及表中文件；无 `console.log` 残留。
- 完成后运行 `trellis-check`。

## 回滚点

- 每个文件独立，可逐个还原；无数据迁移。
