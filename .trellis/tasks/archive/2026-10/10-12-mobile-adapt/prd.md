# 适配移动端

## Goal

让游戏在手机 / 平板浏览器上**横屏**可完整游玩：触屏能完成全部操作（含取消），攻击前能看到伤害预测，不会出现误滚动、误缩放，操作说明与设备一致。

## 已确认的决策

- 屏幕方向：只支持横屏，保留现有 1200×672 布局；竖屏时显示“请横置设备”遮罩。不做竖屏单独布局。
- 触屏交互：选目标时“第一次点击预览、再点同一格执行”；地图上提供浮动“取消”按钮代替右键 / ESC。
- 指令菜单按钮在触屏上仍是点击即执行（不做二次确认）。

## 现状问题（读代码确认）

1. `index.html` 没有禁用双指缩放、双击缩放、长按菜单、文字选择。
2. 取消只能用右键 / ESC（`BattleScene` 指针与键盘监听），触屏无法取消指令菜单、无法退出选目标。
3. 战场 `onHover` 只挂在 `pointermove` 上；触屏单击不触发 move，信息面板、光标、伤害预测、范围预览都不刷新，点目标直接执行。
4. `MapCamera.update` 的边缘滚动依赖 `input.isOver` 和 `activePointer` 位置；触屏抬起后指针停在原处、`isOver` 仍为真，点过地图边缘后镜头会持续滚动。
5. 天气说明靠悬停显示，触屏抬起即触发 `pointerout` 被还原，看不到。
6. 标题页、营中、剧情、整备、选目标提示等文字写的是“左键 / 右键 / ESC / 空格 / 鼠标”。
7. 点击 / 拖动阈值 `DRAG = 6` 是游戏坐标；手机横屏画面缩放约 0.58，相当于 3.5 个 CSS 像素，手指轻微抖动就会把点击判成拖动，点格子没反应（地图不可滚动时也一样被吞掉）。
8. 存档“导入”按钮在 `pointerdown` 里调用 `input.click()` 打开文件选择；触屏的 `pointerdown` 来自 `touchstart`，不是浏览器认可的用户激活事件，手机上可能打不开文件选择。
9. 没有禁止下拉刷新 / 越界回弹（Android Chrome 下拉会刷新页面，丢失战斗进度）。

## Requirements

- R1 页面：禁止页面缩放（双指、双击）、长按菜单和文字选择；触屏设备首次触摸时尝试进入全屏并锁定横屏（浏览器不支持时静默忽略）。
- R2 竖屏遮罩：粗指针设备竖屏时整屏显示“请将设备横置”提示；转回横屏后提示消失，游戏画面自动适配。
- R3 触屏点击战场格子时，与鼠标悬停一样刷新光标、单位 / 地形信息、伤害预测和范围预览。
- R4 选目标状态下，触屏第一次点击有效目标只预览（显示预测，并在目标格上方标“再点确认”），再点同一格才执行；点其他格切换预览对象。鼠标操作不变。
- R5 触屏设备在移动 / 指令菜单 / 选目标状态显示“取消”按钮（位于右侧面板，不遮挡地图），效果等同右键取消；对白、弹窗、敌军阶段时隐藏。
- R6 触屏操作不触发地图边缘滚动；拖动滚动、小地图跳转保持可用。
- R7 天气说明在触屏点击后保持显示（不随抬起还原）。
- R8 面向玩家的操作说明在触屏设备上改为触屏版本：标题页说明、营中底部说明与互动提示、剧情“按住加速”、整备装备页说明、宝物图鉴说明、选目标提示；触屏选策略 / 道具后，选目标提示中带该策略 / 道具说明。
- R9 触屏点击判定容差放大到约 18 游戏像素（≈10 CSS 像素），鼠标保持 6。
- R10 存档界面“导入 / 导出全部 / 单个存档导出”按钮在触屏时改为抬起时触发，保证能打开文件选择 / 触发下载。
- R11 禁止下拉刷新与越界回弹；补充 iOS / Android“添加到主屏幕”后的全屏 meta。

## Acceptance Criteria

- [ ] 手机横屏（如 844×390 视口、触屏模拟）能完成：标题 → 新游戏 → 剧情 → 整备 → 战斗中移动 / 攻击 / 策略 / 道具 / 取消 / 结束回合 → 存读档。
- [ ] 选目标时第一次点击显示伤害预测且不执行，再点同一格执行；桌面鼠标单击仍直接执行。
- [ ] 触屏下“取消”按钮在 move / menu / target 状态可见且生效，其他状态隐藏；桌面端不显示该按钮。
- [ ] 大地图关卡触屏点击地图边缘后镜头不会自行滚动；拖动滚动正常。
- [ ] 竖屏显示横置提示；横屏无遮罩。
- [ ] 触屏轻点（手指有少量位移）仍判定为点击；明显拖动才滚动地图。
- [ ] 手机上存档界面“导入”能打开文件选择（需真机确认）。
- [ ] 取消按钮不遮挡任何地图格子。
- [ ] 桌面端行为与改动前一致（悬停、右键、ESC、边缘滚动、键盘）。
- [ ] `npm run build` 通过，控制台无新增错误。

## Out of Scope

- 竖屏专用布局、界面整体放大或字号调整（小屏文字偏小为已知限制）。
- 营中键盘移动的虚拟摇杆（点击行走已可用）。
- 新增设置项（如关闭全屏）。
- iPhone Safari 不支持网页全屏 API（地址栏会占用高度），只能靠“添加到主屏幕”获得全屏。
- 多指操作：Phaser 默认只启用 1 个触摸指针（`input.activePointers = 1`，已读 `core/Config.js` 确认），第二根手指会被忽略，无需处理。
