# 招募系统：金币、招募小兵与武将

## 目标

玩家可用金币（现有"军资金"）招募通用小兵与非剧情武将来扩充军队；新游戏第一战前即可招募。

## 背景（代码事实）

- 金币已存在：registry `gold`，新游戏为 0（`src/scenes/TitleScene.js:201`），每胜一关得 `lordLvl*100+700` + 关卡奖励（`src/equipment.js:18`），已有商店（`src/prep.js:324-386`）并已进存档（`src/saves.js:59-75`）。本任务沿用该金币，只新增招募用途与开局金币。
- 剧情武将 `GENERALS` 26 人（`src/data.js:172-199` / `src/generals.js`），`isGeneral` 是花名册统一门槛（`src/generals.js:30`）。
- 其他武将外形表 `CHARACTERS` 181 条（`src/characters.js`），基本为敌军 / 友军 / NPC。
- 第一关前没有营地，但第一战前有整备界面（`src/story/flow.js:5`、`src/prep.js`）。
- 出战人数由关卡出战格决定（`src/deploy.js:59-121`）。

## 已决策

- D1 武将池：`CHARACTERS` 中排除 `GENERALS`、君主及非战斗 / 特殊人物后的武将。已招募武将之后在剧情中作为敌将出现时照常出现（平行世界，不改战斗生成）。
- D2 刷新：每个关卡间隙自动生成一批新候选，并有 3 次免费手动刷新，每关重置。
- D3 入口：整备界面新增"招募"页签（战前、营地大帐都可用），营地另设募兵官 NPC 直接打开招募页。
- D4 小兵：固定兵种列表（步兵 / 弓兵 / 骑兵 / 策士 / 风水士）任选、不刷新、可无限招募，自动命名，能力弱于武将、价格便宜；武将只能从随机候选中招募。
- D5 数值：开局金币 1000；招募单位等级 `max(1, 曹操等级-1)`；小兵价格 `300+等级×10`，武将价格 `800+等级×30`。

## 需求

- R1 整备界面"招募"页可花金币招募小兵与武将。招募单位永久进入花名册，可出阵、装备、升级、转职，并随存档保存。
- R2 武将候选不含 `GENERALS` 中的武将、排除名单中的人物以及已招募的武将。
- R3 每关候选 4 名，可手动刷新 3 次；进入下一关后候选换批，刷新次数重置为 3；读档不能重置次数。
- R4 新游戏第一战前的整备界面即可招募，开局金币 1000。
- R5 营地募兵官可打开招募页。
- R6 招募后，阵容、装备页立即可见新成员。

## 验收标准

- [ ] 新游戏第一战整备界面有"招募"页，军资金显示 1000
- [ ] 招募扣除对应金币；金币不足时按钮置灰或提示，无法招募
- [ ] 武将候选从不出现 26 名剧情武将及排除名单中的人物，已招募的武将不再出现
- [ ] 刷新 3 次后刷新按钮置灰；下一关时候选变化，次数恢复为 3
- [ ] 招募后不关闭界面，切到阵容页即可看到并选择新成员出阵
- [ ] 招募单位在战斗中正常行动、获得经验；胜利后等级被保存
- [ ] 营地募兵官可招募；营中人物中出现已招募武将
- [ ] 存档后读档，招募单位、候选列表、刷新次数保持不变；旧存档可正常读取
- [ ] `node scripts/validate-stages.mjs` 零错误，`npm run build` 通过

## 不在范围内

- 解雇 / 遣散招募单位
- 修改现有金币获得公式与商店
- 剧情中同名敌将的屏蔽或替换
- 为小兵新增外形 / 立绘素材（使用默认外形）
- 招募武将的专属台词或剧情
