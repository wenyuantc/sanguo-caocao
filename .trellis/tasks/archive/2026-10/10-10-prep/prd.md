# 出阵整备与情报界面

## Goal

像原版一样，开战前由玩家从已加入的武将中挑选出阵阵容；战斗中可以查看全军情报。
同时修复导入存档的校验 bug。

## Background（代码现状）

- 我军阵容写死在各关 `units` 中（`src/stages/a.js`–`f.js`），由 `BattleScene.create()` 直接生成。
- 我军成长只记在 registry `roster` 中：`{ [id]: { lvl, exp } }`。
- 部分关卡在剧情事件中途生成我军武将，例如 zhangxiu1 第 3 回合曹洪、于禁，machao 第 4 回合徐晃、张郃。
- 夏侯渊第 16 关起兵种由 archer 改为 archercav；临时成员有白马、延津的关羽（`guanyu`）和献帝（`xiandi_emp`）。
- Bug：`saves.validSave` 要求 `Number.isInteger(d.stage)`，而当前存档里的关卡是字符串 id，导致当前版本导出的文件导入失败（见 `.trellis/spec/frontend/state-management.md`“已知问题”）。

## Requirements

- P1 **武将总表** `src/generals.js`：列出全部可加入的我军武将，含名字、默认兵种、bonus，以及阵亡 / 离队标记（`dianwei_dead`、`guojia_dead`、`j_xiahouyuan_dead`、`j_yujin_captured`、`j_pangde_dead`）。
- P2 **加入记录**：
  - 武将首次作为预设我军出现在某关时，加入 registry `joined`。
  - 武将总表可以给武将指定 `joinAt`（关卡 id，分路线时用 `{ loyal, villain }`），进入该关时自动加入。用于关卡数据里没有、原版却有的武将：满宠（原版第 11 关）、貂蝉（第 16 关）、曹丕（第 23 关）。他们只进入出阵候选，不改关卡对白。
  - 旧存档没有 `joined` 时，用 `roster` 的键推导。
- P3 **出阵规则**（不改动 57 关数据，自动推导）：
  - 出阵位置 = 该关预设我军单位的站位；出阵上限 = 位置数。
  - 必须出阵：曹操；不在武将总表中的临时成员；在本关胜利条件、`protect`、`escape`、事件（duel、onDeath、setAi）中出现的我军武将；本关开场 / 结尾对白中发言的我军武将。
  - 不可出阵：带阵亡 / 离队标记的武将；本关剧情事件中途生成的我军武将。
  - 默认勾选 = 该关预设阵容（不改选时，行为与现状一致）。
  - 单关可用 `deploy: { max, required: [id], slots: [[x,y]] }` 覆盖推导结果。
- P4 **出阵武将的数据**：
  - 等级：取 roster 等级与关卡下限中较大的一个；不在本关预设中的武将，下限为本关曹操下限 − 1。
  - 兵种：取本关预设兵种；不在预设中的武将，取 roster 中记录的上次兵种，再退回总表的默认兵种。
- P5 **整备界面**：开场剧情之后、开战横幅之前弹出（读取战斗中的存档时不弹出）。
  - 每张武将卡片显示头像、名字、兵种、等级、兵力。
  - 点选可上场 / 下场；必须出阵的锁定并标注“必须出阵”；已满员时不能再选。
  - 显示“出阵 n / 上限”；提供“恢复默认”“出　阵”按钮。
- P6 **生成我军**：确认出阵后生成我军。必须出阵且在预设中的武将用原站位，其余选中的武将依次填入剩余站位。
- P7 **部队情报界面**：顶部栏加“部队”按钮，在我军阶段可以打开。
  - 分我军、友军、敌军三页，列出名字、兵种、等级、兵力 / 上限、策略值、是否已行动。
  - 点击某行：关闭界面，光标移到该单位，右侧信息面板显示该单位。
  - ESC 或“关闭”退出，退出时清理监听。
- P8 **存档**：
  - `joined` 进入新游戏重置、`snapshot()`、`writeAuto`、`applyLoad`。
  - `roster` 增加 `cls`，旧存档缺失时按 P4 推导。
  - 修复 `validSave`：关卡字段接受字符串 id 或数字。

## Acceptance Criteria

- [ ] 新游戏第 1 关：整备界面显示曹操、夏侯惇、夏侯渊、曹仁，曹操锁定；直接确认后与现状阵容、站位完全一致。
- [ ] 中期关卡（如官渡）：可以把未预设的已加入武将换上场，换上的武将等级、兵种正确，站在空出的预设位置。
- [ ] 必须出阵的武将（如白马之战的关羽、宛城之战的典韦和郭嘉）不能取消；宛城之战中曹洪、于禁不在可选名单里。
- [ ] 典韦阵亡后，他不再出现在任何整备名单中。
- [ ] 部队情报界面三页数据正确；点击某行后光标定位到该单位。
- [ ] 战斗中存档 → 读档，不弹出整备界面，阵容不变。
- [ ] 旧格式存档（没有 `joined`、roster 没有 `cls`）可以读取并继续。
- [ ] 当前版本导出的存档文件可以成功导入。
- [ ] 校验 0 错误，构建通过，57 关回归无运行时错误。
