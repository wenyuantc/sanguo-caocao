# 游戏设置与渲染性能

## 背景
游戏偶尔卡顿。画布固定按 2 倍分辨率渲染，且无法调节；另发现两个与分辨率无关的性能热点：
鼠标在格内移动时反复重建信息面板、地图 Graphics 每帧重新处理数千条绘制指令。

## 需求
1. 标题页新增「游戏设置」按钮，打开设置弹窗，可设置：
   - 渲染分辨率：自动 / 1x / 1.5x / 2x
   - 画质：高 / 低（低 = 关闭抗锯齿与单位待机动画）
   - 帧率上限：30 / 60 / 不限
   - 显示帧率：开 / 关
   - 全屏：切换按钮（立即生效）
2. 设置持久化到 localStorage，损坏时回退默认；需重载才生效的项在「保存并应用」后重载页面。
3. 鼠标在同一格内移动时不再重建 HUD 信息面板；跨格时正确刷新。
4. 地图烘焙为静态贴图，外观与原先一致。

## 验收标准
- [ ] 各设置项保存后重载生效（画布尺寸、抗锯齿、帧率上限、帧率角标）。
- [ ] 损坏的 `sanguo-settings` 能回退默认，不报错。
- [ ] 战斗地图外观一致；悬停、选中、移动、攻击、策略预览、对白、存读档流程正常。
- [ ] `npm run build` 通过，`node scripts/validate-stages.mjs` 0 错误。
