# 音频引擎与音效（10-10-audio 子任务 1/2）

## Goal

搭好 Web Audio 实时合成的音频底座（不使用音频文件），做出全部音效并接入各动作，提供音量设置。配乐所需的乐器音色也在这里完成，供子任务 2（`10-11-audio-music`）直接使用。

## Requirements

- E1 **引擎**（`src/audio/engine.js`）：单例管理 `AudioContext`；主音量，配乐 / 音效两个总线；程序生成脉冲响应的简单混响；首次用户操作后解锁；切到后台暂停、回来恢复。
- E2 **音色**（`src/audio/instruments.js`）：古筝 / 琵琶（拨弦）、笛子（正弦 + 颤音 + 气声噪音）、二胡（锯齿波滤波 + 滑音）、编钟、大鼓 / 小鼓 / 锣。统一签名，可指定输出总线，音符结束后自动断开节点。
- E3 **音效**（`src/audio/sfx.js`）：
  - 选择、确认、取消；移动脚步；
  - 13 种兵器的攻击；命中、会心、闪避；
  - 各系策略（火、水、地、风、异常、增益、回复）；
  - 升级、转职、得到道具或宝物、单位撤退；天气变化；回合开始。
  - 同时发声的音效最多 8 个。
- E4 **接入**：按钮点击、单位移动、攻击、策略、升级 / 转职、道具 / 宝物、撤退、天气变化、回合开始处调用音效。
- E5 **设置**：在现有设置面板（`settings.js` / `settingsMenu.js`）中加入配乐音量、音效音量、静音；保存在 localStorage；改音量即时生效，不重载页面；标题页和战斗中都能打开（战斗中只显示音量相关的行）。
- E6 **浏览器限制**：标题画面提示“点击开始”，首次点击 / 按键后解锁音频。

## Acceptance Criteria

- [ ] E3 列出的音效都能触发（浏览器脚本逐个触发），音量合适、不刺耳。
- [ ] 各乐器音色可用测试函数单独播放，听感可辨。
- [ ] 音量与静音设置即时生效，刷新后保持；改音量不触发页面重载；渲染设置的原有行为不变。
- [ ] 战斗中能打开音量设置并关闭后继续游戏。
- [ ] 切到后台无声，回来恢复。
- [ ] 连续触发大量音效后活动节点数回落，无泄漏。
- [ ] `npm run build` 通过；57 关回归无运行时错误。

## Out of Scope

- 曲目、音序器与场景配乐切换（子任务 2）；语音；模仿原版音效。
