# 军营与城镇自由走动（超出原版）

## Goal

两关之间进入军营或城镇场景，玩家操控曹操自由行走，走近部下或百姓对话获取情报和建议；可以在场景里进入整备（出阵、装备、商店）、存档，然后出征。
父任务决定 D6：原版只有点击部下交谈（research/scenes.md §3），自由走动是本项目的扩展。

## Requirements

- T1 **时机**：每关结尾场景之后、下一关开场场景之前进入。新游戏的第 1 关跳过（直接开场）。
- T2 **场景**：
  - 复用剧情场景（子任务 7）的背景与人物；
  - 场景类型按剧情地点选择：军营（多数）、城镇（许昌、邺城等据点时期）、野外营地；
  - 场景有可走区域和障碍（帐篷、案几、房屋、树木）。
- T3 **行走**：
  - 点击地面寻路走过去，或用方向键 / WASD 行走；四方向行走动画；
  - 镜头跟随曹操；不能穿过障碍和人物。
- T4 **人物**：
  - 已加入的我军武将在营中，位置随机但避开障碍；部分站岗、部分闲逛；
  - 城镇另有百姓、商人等通用角色。
- T5 **对话**：
  - 走近并点击（或按空格 / 回车）与人物对话；
  - 内容优先使用本关专属台词（对下一战的情报、建议、闲谈），没有时使用按武将个性写的通用台词；
  - 对白可以带选项，选项可以影响红色指数或剧情标记，与原版军营交谈的作用相同。
- T6 **功能点**：
  - 商人 → 打开商店页；
  - 曹操的大帐或军需官 → 打开整备界面（出阵、装备、道具）；
  - 营门 → 确认出征，进入下一关开场；
  - 任意时刻可以存档（存档类型为“营中”，读档回到营中）。
- T7 **内容**：
  - 57 关各写 3–6 位人物的本关专属台词，围绕下一战的地形、敌将、计策；
  - 全体我军武将各写 3 条以上通用台词。
- T8 **持久化**：营中存档记录：所在关卡（下一关 id）、已对话人物、registry 状态。读档时回到营中。

## Acceptance Criteria

- [ ] 每两关之间都会进入营中场景，可以自由行走、对话；镜头跟随；寻路避开障碍。
- [ ] 本关专属台词出现在正确的关卡；没有专属台词的人物说通用台词。
- [ ] 商人、整备、营门三个功能点可用；营中存档读档正确。
- [ ] 营中选项对红色指数和剧情标记的影响生效。
- [ ] 校验脚本检查营中台词数据（人物名、关卡 id、选项格式）；0 错误；构建通过；57 关回归无运行时错误。

## Out of Scope

- 营中小游戏、营中随机事件。

## 追加需求（PR #7 评审后，2026-10-11）

- T9 **自动存档进营中**：
  - 胜利时写入的自动存档改为营中类型（`kind: 'camp'`，下一关、空 talked），读取后回到营中；
  - 从营门出征时再写一次自动存档（`kind: 'stage'`，包含营中选项与选好的阵容），读取后进入下一关开场；
  - `stageStartSave`（地图版本不一致时找本关开头状态）两种类型都要接受，优先使用出征时写入的那份；
  - 旧的 `kind: 'stage'` 自动存档行为不变。
- T10 **营中剧情标记要有后果**：营中选项设置的每个剧情标记，都要在之后的关卡数据中被读取（至少一处），形式可以是：
  - 下一关开场 / 结尾 / 事件 / 场景中按 `ifFlag` / `unlessFlag` 出现的对白；
  - 合适时再加小的玩法影响（按标记出场的友军、提前或延后的事件、敌方行为变化等），不改装备奖励表（`equipment.js` 由整合阶段维护）。
  - 校验脚本检查：营中设置的标记没有被任何关卡数据或营中台词读取时报错。
- T11 出征确认框支持回车确认、ESC 取消。

### 追加验收
- [ ] 胜利后的自动存档读取回到营中；营门出征后的自动存档读取进入下一关开场，营中选项保留。
- [ ] 所有营中剧情标记至少被读取一次，校验 0 错误；抽查若干关选不同选项后对白或战场确有不同。
