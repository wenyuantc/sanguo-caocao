## Findings

### 1. 装备分类与栏位

- 每个武将有 **武器 / 护具 / 辅助** 三个装备栏（E1 把宝物分成"AT（武器）/ DT（护具）/ 辅助"三类；E5 的宝物图鉴也分"武器、护具、辅助"）→ **多源一致**。
- E8 给出的完整物品编号（00~56，共 87 种装备）：

| 编号 | 类别 | 物品 |
|---|---|---|
| 00~14 | 普通武器（21） | 短剑、大剑、钢剑；短枪、长枪、钢枪；短弓、大弓、铁弓；木棍、铜棍、铁棍；木制投石机、铜制投石机、铁制投石机；竹扇、军扇、铁扇；石制宝剑、铜制宝剑、铁制宝剑 |
| 15~25 | 宝物武器（17） | 雌雄双剑、青釭剑、倚天剑、古锭刀、青龙偃月刀、蛇矛、方天画戟、吕布之弓、李广之弓、流星锤、双鞭、金火罐炮、芭蕉扇、五火神焰扇、白羽扇、七星剑、圣者宝剑 |
| 26~2B | 普通护具（6） | 皮铠、铜铠、铁铠、布衣、皮衣、战斗服 |
| 2C~34 | 宝物护具（9） | 镜铠、黄金铠、连环铠、白银铠、龙鳞铠、飞龙道袍、鹤氅、漆黑道服、凤凰羽衣 |
| 35~56 | 辅助（34，普通+宝物混排） | 皮盾、铜盾、**白银盾**、**风神盾**、皮制马铠、铜制马铠、**风车轮**、**爪黄飞电**、**绝影**、**赤兔马**、**的卢**、皮盔、铜盔、**铁盔**、方巾、纶巾、**诸葛巾**、布手套、皮手套、**没羽箭**、**孙子兵法**、**孟德新书**、**青囊书**、**太平清领道**、**太平要术**、**遁甲天书**、**六韬**、**三略**、**豆袋**、**玉玺**、**青龙宝玉**、**朱雀宝玉**、**玄武宝玉**、**白虎宝玉**（粗体为宝物） |

  E9 的编号表和 E8 基本一致，只有个别用字不同：E9 写"长弓""钢棍""木投石车"；E9 在 37 号写"钢盾"，但 E8 是"白银盾"，且其他所有来源都没有"钢盾"，疑为 E9 笔误。→ 名单**多源一致**。
- 普通装备共 21+6+10 = 37 种，宝物 50 种。E2 说"总共 68 种道具，其中含 50 种具有特殊功能、不能在道具店购买的宝物"，与 87 种不符（可能 E2 统计口径不同），**未能确认**。

### 2. 武器种类与可装备职业

E7 说"武器共分为 7 种：剑、枪、弓、棍、投石机、扇和宝剑"；E1 给出各类宝物可装备的兵种。两者对得上 → **多源一致**。

| 武器种类 | 初级 / 中级 / 高级（普通品） | 可装备系列 | 同类宝物 |
|---|---|---|---|
| 剑 | 短剑 / 大剑 / 钢剑 | 君主、步兵、贼兵 | 雌雄双剑、青釭剑、倚天剑、古锭刀 |
| 枪 | 短枪 / 长枪 / 钢枪 | 骑兵 | 青龙偃月刀、蛇矛、方天画戟 |
| 弓 | 短弓 / 大弓（E9 写"长弓"） / 铁弓 | 弓兵、弓骑兵 | 吕布之弓、李广之弓 |
| 棍 | 木棍 / 铜棍 / 铁棍（E9 写"钢棍"） | 武道家、舞娘 | 流星锤、双鞭 |
| 投石机 | 木制 / 铜制 / 铁制投石机 | 炮车 | 金火罐炮 |
| 扇 | 竹扇 / 军扇 / 铁扇 | 策士、骑马策士 | 芭蕉扇、五火神焰扇、白羽扇 |
| 宝剑 | 石制 / 铜制 / 铁制宝剑 | 风水士、道士 | 七星剑、圣者宝剑 |

护具（E1 的宝物表）：
- **铠**类（镜铠、黄金铠、连环铠、白银铠、龙鳞铠）→ 君主、步兵、弓兵、骑兵、弓骑兵。
- **衣/袍**类（飞龙道袍、鹤氅、漆黑道服、凤凰羽衣）→ 炮车、道士、风水士、策士、贼兵、武道家、骑马策士、舞娘。
- 普通护具中，皮铠/铜铠/铁铠属于铠类，布衣/皮衣/战斗服属于衣类（E7/E11 把"铠甲类""布衣类"分开说）。普通护具的可装备兵种是否与同类宝物完全相同，**没有直接查到**（按同类推定）。

辅助（E1）：大多数辅助宝物"所有种类皆可装备"，例外：风车轮只能炮车装备，铁盔只能步兵装备，没羽箭只能贼兵装备，四宝玉只能对应文官系列装备。**普通辅助**（盾、马铠、盔、巾、手套）的可装备兵种与数值**未能查证**。E12 说铁盔"是所有头盔中效果最好的，可使装备者的最大 HP 大幅上升"、诸葛巾"是所有头巾中效果最高的，可使最大 MP 大幅上升"，所以普通盔可能加 HP、巾可能加 MP（单一来源，且是推断）。

### 3. 装备升级（武具成长系统）

| 规则 | 内容 | 可信度 |
|---|---|---|
| 经验来源 | 攻击时武器得经验，被攻击时护具得经验；经验满 100 升 1 级 | 单一来源（E5） |
| 等级上限 | 普通装备最高 Lv3；宝物最高 Lv9（9 级时属性达到 E1 的"LV9 最大值"） | Lv3：多源一致（E5/E7/E11）；宝物 Lv9：多源一致（E1/E5/E10 "可以直接获得 9 级装备"） |
| 内部上限 | 修改存档时宝物等级"最大是 255"（E9） | 单一来源，属于修改器范畴 |
| 普通装备三档 | 初级 / 中级 / 高级，商店随剧情推进上架更高档（E7："根据剧情，商店武器都会得到进阶"） | 多源一致（E5/E7） |
| 辅助品 | 辅助类是否有经验、能否升级**未能查证** | — |
| 加速成长的宝物 | 六韬（每回合武器经验）、三略（每回合护具经验）、孟德新书（获得经验 ×1.5，E6"增加 50%"）、孙子兵法（每回合经验，E6"每回合增加经验 4"） | 效果名称多源一致（E1/E6/E12）；具体数值单一来源 |
| 新武将自带装备等级 | 武将等级 1~7 级加入带 1 级初级装备，之后每 4 级装备升一档：8~11 → 初级 2 级，12~15 → 初级 3 级，16~19 → 中级 1 级，20~23 → 中级 2 级，24~27 → 中级 3 级，28~31 → 高级 1 级，32~50 → 高级 2 级（不会带 3 级高级装备） | 单一来源（E10），E5 的"装备加入等级 = 武将加入等级/4，最高 8 级"与之吻合 → 多源一致 |
| 宝物等级 | 宝物加入时等级 = 曹操等级/4 + 1；武将自带宝物等级 = 武将等级/4 + 1；战利品等级 = 曹操等级/4 + 1 | 单一来源（E5） |

### 4. 卖出得果子

把 **Lv3** 的普通装备卖给商人，得到对应的果子（E16 维基："賣出較高等級的裝備，可以獲得提升各項能力屬性……的果子"）：

| 卖出的装备 | 得到 | 可信度 |
|---|---|---|
| 剑 | 经验果 | 多源一致（E5/E7/E11） |
| 枪 | 武力果 | 多源一致 |
| 投石机 | 武力果 | 多源一致 |
| 弓 | 好运果 | 多源一致 |
| 棍 | 好运果 | 多源一致 |
| 扇 | 智力果 | 多源一致 |
| 宝剑 | 智力果 | 多源一致（E5/E11；E7 原文写成"3 级的扇卖掉得智力果"，应是笔误） |
| 铠甲 | 统率力果 | 多源一致（E5/E11） |
| 衣服 | 敏捷果 | 多源一致（E5/E11） |
| 辅助品 / 宝物 | 能否换果子**未能查证** | — |

果子效果：吃 1 个对应基础能力 +2（E5）。经验果的效果**未能查证**（E7 只说"最没用"）。

4. 扇、宝剑类加的是攻击力还是精神力，E1 与 E12 写法不同，未能核实（倾向于精神力）。
5. 取得条件有冲突的宝物：白羽扇（蓝线能否取得）、绝影（全灭 vs 击退李儒）、孙子兵法（张纮 vs 张昭）、濡须口之战的两把弓、白银铠在长坂坡/成都的条件、爪黄飞电（蓝线）。

8. 关卡编号以 E5 为准；不同攻略对关卡序号的计法可能不同（例如是否计入董卓追击战、濮阳之战二/三等可跳过的关卡）。
