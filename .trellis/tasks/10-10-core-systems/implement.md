# 实施顺序（总体）

1. `10-10-prep`：武将总表、出阵整备、部队情报、修复导入校验 bug。
2. `10-10-promotion`：兵种体系、五项能力、原版 HP/MP 公式、我军改为原版兵种、敌方特殊兵种、印绶转职。
3. `10-10-status`：原版策略体系、异常状态、增减益、原版消耗品。
4. `10-10-equipment`：87 种装备与宝物、升级、果子、奖励与掉落、金钱与商店。
5. `10-10-weather`：天气、天气策略、四神。
6. `10-10-bigmap`：大地图引擎、30 种地形、57 关地图重做与站位重排（子代理按组并行）。
7. `10-10-scenes`：剧情场景演出、战场剧本演出。
8. `10-10-town`：军营与城镇自由走动、营中台词（子代理按组并行）。
9. `10-10-audio`：程序合成配乐与音效。
10. `10-10-ngplus`：结局记录、宝物图鉴、二周目开局选项。

每个子任务依次执行：`task.py start` → trellis-implement → trellis-check → 浏览器实测与回归 → trellis-update-spec → 提交 → 归档，然后进入下一个子任务。
每个子任务完成后向用户汇报一次结果，再继续下一个。
